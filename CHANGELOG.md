# Changelog

## 1.0.0

- Verify browser workflows against bundled fixtures and explicitly authorized read-only targets. Author workflows, scoped response mutations and business rules in the workspace.
- Capture silent regressions and observed dependency graphs, isolate triggering changes, and export executable Playwright specs and JSON, HTML or PDF evidence.
- Verify reviewed static replacements and the Fieldwork repair in isolated snapshots. Apply a configurable CLI deployment gate to recorded reports.
- Preserve catalogs and runs in JSON or MongoDB. Add optional operator authentication and a private SSH-tunneled deployment configuration.
- Document the Fieldwork and Room Board benchmarks, setup, demo, security model and known limits.

## 0.1.0

- Added API discovery, response mutation, browser evidence, business rules, and bounded failure isolation.
- Added the evidence dashboard, dependency graph, generated tests, reviewed repair, and CI gate.
- Added a reproducible 30-scenario synthetic benchmark.
