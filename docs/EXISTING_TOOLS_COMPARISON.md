# Existing tools comparison

| Established technique                        | Primary source                                                                                                | How BreakTrace uses or relates to it                                                                                                             |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Browser interception and synthetic responses | [Playwright API mocking](https://playwright.dev/docs/mock)                                                    | Replays named workflows with control and mutant contexts and stores browser evidence for each run.                                               |
| Consumer-driven API contracts                | [Pact introduction](https://docs.pact.io/)                                                                    | Uses observed response shapes and UI rules to measure which workflow behavior changes under a selected response mutation.                        |
| Schema-driven property-based API tests       | [Schemathesis](https://schemathesis.readthedocs.io/en/stable/)                                                | Imports OpenAPI JSON for the explorer, then uses curated browser scenarios and registered assertions to evaluate controlled response deviations. |
| Reduction of a failure-inducing input        | [The Debugging Book by Andreas Zeller and collaborators](https://www.debuggingbook.org/classic/DeltaDebugger) | Applies bounded subset reduction to API response mutations while comparing normalized browser finding signatures.                                |

The proposal is an integrated local workflow from response interception to observed frontend impact, reproducibility, a generated browser test and repair evidence. Claims about market novelty, comparative effectiveness, real-world failures found, and production deployment outcomes require independent evaluation.
