# Roadmap

1. Establish a local TypeScript workspace with reproducible build, lint and test commands.
2. Compare baseline and mutated checkout sessions and surface the resulting evidence.
3. Add declarative rules, discovery, dependency graphs and bounded minimization.
4. Generate browser regression tests, verify a reviewed demo patch and enforce configurable CI gates.
5. Harden browser and API boundaries, document local deployment and validate the dashboard.
6. Run a labeled synthetic benchmark and publish its raw results with portfolio documentation.

Multi-operator hosting, external target enrollment and distributed workers require a separate trust model and persistence design.
